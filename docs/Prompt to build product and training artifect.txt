Prompt 1 — you describe the product:

Build a new product for the [TEMPLATE NAME, e.g. Printing Shop] template, called
"[PRODUCT NAME]", matching the same style as the existing products in that
template (e.g. how Banners is built).

1. Product — a short, realistic name, a one-sentence plain-English description,
   and a sensible starting Base Price.

2. Questions — mostly Single Choice, one per real decision a customer makes
   when ordering this (material, size, finish, quantity, add-ons, etc.).
   Every option gets a price adjustment: $0 for the standard choice, positive
   for upgrades, negative for bulk-quantity discounts — same pattern as the
   existing products use.

3. At least one conditional question — something that only appears depending
   on an earlier answer (e.g. an "enter custom size" text box that only shows
   up if Size = Custom).

4. Rules for anything that isn't a simple per-option price bump — a volume
   discount percentage, a flat add-on fee, that kind of thing.

5. Publish it once it's built, and confirm the pricing actually calculates
   correctly by running a sample quote through it.

6. Build a Training Artifact (build sheet) for it, in the same styled,
   theme-aware format the existing ones use — overview panel, every
   question/option/rule listed in order, and step-by-step "where to click"
   instructions so a staff member could manually rebuild it by hand.

7. Export it as a ready-to-upload SQL file using the product:export-sql
   command, and send me the file — I'll paste it into phpMyAdmin on the
   live server myself.

Here's what I want the product to actually offer:
[Describe it in your own words — what it is, what choices a customer picks
from, roughly what should cost more or less, and any discounts/fees that
should apply. No need to know question types or pricing formats — just
describe it like you're explaining it to a new employee.]
