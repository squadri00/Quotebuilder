STEP 1 — Design one realistic scenario
Using the PRODUCT DESCRIPTION above, pick one specific, realistic type of
business/product (not the whole industry in the abstract). Design:
  - 12-15 questions, in the order they must be entered (a question with
    conditional logic can only reference a question already listed above it)
  - Mostly Single Choice questions with 3-5 priced options each; include
    at least one Number question and one Text question
  - 2-3 of the questions should be conditional — only shown depending on
    an earlier answer (use both "is" and "is not" comparisons across them)
  - 5 rules at the end, covering a mix of: fixed-dollar fee on a matched
    option, fixed-dollar fee on a number threshold, a percentage surcharge,
    an option-price override, and one more fixed-dollar fee

STEP 2 — Self-check your own design
Since you can't actually run this, verify it by re-reading what you just
wrote instead:
  - Every conditional question's referenced "Question:" name and "Answer:"
    option label must exactly match the text of an earlier question/option
    in your own list — check this by eye, word for word.
  - Every rule's "When" question and option/value must exactly match text
    you wrote in a question card above it.
  - Every rule's "Then" action must be one of exactly three types: add a
    fixed dollar amount, add a percentage, or set a specific option's
    price to a new dollar amount — nothing else exists as an option.
  - Walk through one full path by hand (pick one answer per question,
    following your conditional logic) and compute what the final price
    would be from base price + selected option prices + any rules that
    fire. Report that computed total in the closing paragraph.
