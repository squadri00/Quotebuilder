How to use this

Build it in this order — a question with conditional logic can only reference a question that already exists above it, so entering them out of order will leave you with nothing to pick from.

  1. Super Admin → Templates → New Template — name it, set the Industry, save. You'll land straight in its Quote Builder.
  2. New Product — enter the Product Name and Base Price from the panel above.
  3. For each question below: Questions → New Question, fill in Question Text / Answer Type / Sort Order, then add its Options underneath (Options → New Option) with the label and price shown.
  4. Where a card has a teal conditional logic box, tick "Only if certain earlier answers match" on that question and fill in exactly what the box says.
  5. Once all questions are in, go to Rules and add the ones below.
  6. Click Publish, then hit Preview to walk through it yourself.

Rules

Add these after all questions exist — a rule can only reference a question and option that are already saved.

01Walnut Handling Fee
When Question What wood species should be milled? is Walnut Then Add a fixed dollar amount → $85
02High-Volume Milling Fee
When Question How many boards are required? greater than 200 Then Add a fixed dollar amount → $120
03Custom Moisture Surcharge
When Question What moisture level is required at delivery? is Custom 8–10% Moisture Then Add a percentage → 12%
04Walnut Thick-Stock Override
When Question What wood species should be milled? is Walnut Then Set a specific option's price → option 8/4 (2") → new price $90
05Expedited Production Fee
When Question When is the lumber required? is Expedited — 3–5 Business Days Then Add a fixed dollar amount → $175

Hand-check walkthrough: select Walnut (+$75), Premium Grade (+$85), 8/4 (2") (+$65, overridden to +$90 by Rule 4), 15–18 inches (+$110), 11–12 feet (+$75), enter 240 boards (Rule 2 adds $120), choose S4S — Four Sides Planed (+$45), choose Cabinet-Ready Sanded (+$60 because Rule 9's condition is met), choose Custom 8–10% Moisture (+$45 and Rule 3 adds 12%), choose Local Delivery (+$85), enter any project name, and choose Expedited — 3–5 Business Days (+$175). The pre-percentage subtotal is $1,115.00; the 12% surcharge is $133.80; therefore the hand-checked final price is $1,248.80.
