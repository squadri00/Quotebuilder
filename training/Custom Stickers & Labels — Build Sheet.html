How to use this

Build it in this order — a question with conditional logic can only reference a question that already exists above it, so entering them out of order will leave you with nothing to pick from. This adds a sixth product to the existing Printing Shop template, alongside Banners, Flyers, Business Cards, Brochures, and Signs — a distinct sticker/label product, not overlapping any of those.

  1. Super Admin → Templates → Printing Shop → New Product — enter the Product Name and Base Price from the panel above.
  2. For each question below: Questions → New Question, fill in Question Text / Answer Type / Sort Order, then add its Options underneath (Options → New Option) with the label and price shown.
  3. Where a card has a teal conditional logic box, tick "Only if certain earlier answers match" on that question and fill in exactly what the box says.
  4. Once all 9 questions are in, go to Rules and add the three below.
  5. Click Publish, then hit Preview to walk through it yourself.

Rules

Add these after all 9 questions exist — a rule can only reference a question and option that are already saved.

01Bulk Order Discount (1000+)
When Quantity is 1000+ stickers Then Add a percentage → -10%
02Design Assistance Fee
When Design Service is Need Design Help Then Add a fixed dollar amount → $45.00
03Rush Turnaround Fee
When Preferred Timing is Rush (48-Hour Turnaround) Then Add a percentage → +25%

A good end-to-end test: Holographic material, Custom Die-Cut shape, Large size, UV Laminated finish, 1000+ stickers, Need Design Help, Outdoor/Weatherproof, and Rush timing works out to $227.24 — confirmed against the actual rules engine, including the -10% bulk discount, the +$45 design fee, and the +25% rush fee all applying in sequence on the running total.
