How to use this

Build it in this order — a question with conditional logic can only reference a question that already exists above it, so entering them out of order will leave you with nothing to pick from.

  1. Super Admin → Templates → New Template — name it, set the Industry, save. You'll land straight in its Quote Builder.
  2. New Product — enter the Product Name and Base Price from the panel above.
  3. For each question below: Questions → New Question, fill in Question Text / Answer Type / Sort Order, then add its Options underneath (Options → New Option) with the label and price shown.
  4. Where a card has a teal conditional logic box, tick "Only if certain earlier answers match" on that question and fill in exactly what the box says.
  5. Once all questions are in, go to Rules and add the ones below.
  6. Click Publish, then hit Preview to walk through it yourself.

Rules

Add these after all questions exist — a rule can only reference a question and option that are already saved.

01White Oak Surcharge
When Wood Species is White Oak Then Add a fixed dollar amount → $450
02Extra Drawer Count
When How many drawers should the cabinet system include? greater than 6 Then Add a fixed dollar amount → $300
03Custom Stain Surcharge
When Finish is Custom Stain Then Add a percentage → 12%
04Full Wall Installation
When Cabinet Layout is Full Wall System Then Set a specific option's price → option Full Installation → new price $850
05Butcher Block Handling
When Which countertop should be used on the base cabinets? is Butcher Block Then Add a fixed dollar amount → $175

Hand-check path: choose Full Wall System, 12 ft, White Oak, Shaker, Custom Stain, Soft-close, enter 8 drawers, choose Walnut Tone, choose LED + Outlets, choose Full Installation, choose Stairs / Long Carry, choose Butcher Block, choose Decorative Bevel, and enter any customer notes. The three conditional questions all display: Drawer Count because Cabinet Layout is Full Wall System; Stain Color because Finish is not Clear Coat; and Site Access because Installation is not Customer Pickup. Starting from the $1,800 base, selected option prices total $5,580. Rule 1 adds $450, Rule 2 adds $300, Rule 4 changes Full Installation from $650 to $850, and Rule 5 adds $175, producing a pre-percentage total of $6,705. Rule 3 then adds 12% ($804.60), giving a final hand-checked price of $7,509.60.
